# Лабораторная работа №1. Компьютерная лексикография, терминологические базы (TBX) и Translation Memory (TMX) в Smartcat

ФИО студента: Ключникова Дарья Алексеевна

Группа: ИНФА-221 

Вариант: 7 (предметная область: Нефтегазовая отрасль: добыча и переработка)


Цель: научиться программно обрабатывать стандарты обмена терминологическими данными (TBX) и памятью переводов (TMX), реализовать поиск нечётких совпадений (Fuzzy Match) и подстановку терминов глоссария, экспортировать результат в CAT-систему Smartcat.


# Ход работы:

1. Создание и обработка терминологической базы TBX.

2. Создание и обработка памяти переводов TMX.

3. Поиск совпадений. Реализован поиск похожих сегментов с использованием метрик Levenshtein Ratio и Token Sort Ratio.

4. Классификация совпадений. Реализовано определение типа совпадения в зависимости от степени сходства текста и совпадения контекста.

5. Подстановка терминов. Реализована функция автоматической подстановки терминов из глоссария в текст.
